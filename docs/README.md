# Framework documentation

- [Timed contracts](lean-timed-contracts.md): raw firing, actual scheduler bridges
  and an independently frozen timed benchmark; universal timed model pending.
- [Typed EFSM flow](lean-typed-efsm.md): all five value kinds, universal raw-rule
  contracts, finite test generation and independent C execution through task-v7.
- [IR overview](ir-semantics.md): explicit behavior and backend boundaries.
- [Proposal-role contract](agent-contract.md): provider isolation, shared ledger,
  input pinning and controller-owned acceptance.
- [Extraction](extraction.md): the authoritative maintenance location and frozen
  historical checkers in the protocol case-study repository.
- [Original semantics contract](semantics.md): provenance-preserved source;
  older language/scope descriptions remain at their original bytes.

Start at the [project README](../README.md) for installation and the executable
non-TCP example. The [TCP/IP case study](https://github.com/briliant-ben/TCPIP-Model)
keeps protocol models, network adapters and original observations separately.
