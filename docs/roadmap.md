# Framework milestones

## Implemented baseline

- Declarative Protocol IR, independent reference and formal checks, generated tests,
  standalone C, exact observations/Difference and source traceability.
- Optional independent proposal roles (`gemini` and `deepseek` adapters), pinned
  inputs and a persistent request ledger. Responses cannot self-approve or
  execute model-returned code.
- Compact C expression factoring with retained semantics/failure regressions.
- Lean expression contracts: frozen source/statement hashes,
  proof-data-only workers, actual Lean 4.35.0 checks, a separate axiom audit,
  positive witnesses, mutation/tamper rejection and fresh certificate rechecking.
- Lean-only maintained formal workflows, with no Z3 dependency or fallback.
  The pinned IPv4 endpoint has checked initial admission, all 335 raw firings,
  18 guard conflict groups, timer advance and transactional dispatch contracts.

These are finite, explicit scopes. A passing expression unit is not a proof of
its containing EFSM, the generated C compiler, an Internet standard or TCP/IP.
Existing UNKNOWNs and implementation Differences remain independent evidence.

- A first typed IR / actual C-expression correspondence unit under pinned
  runtime/ABI contracts, with helper expansion, malformed-code rejection and
  rebound-mutant tests. Optional compiled Lean → C reference execution is real,
  but requires Lean's runtime and does not certify either native compiler.

## Next: implementation correspondence

The compact case's five types and 26 pure operators are now represented by typed
Lean data and evaluated by a pure interpreter. Complete case expression typing,
59 kernel obligations and compiled reference values are separate claims. Exact
long-buffer content is preserved, and timer membership is not scheduling. See
[typed values](lean-typed-values.md). The later [timed endpoint proof](lean-timed-contracts.md)
composes transition effects and scheduling for all 335 raw firings. This does
not prove complete TCP/IP behavior, reachability or C compiler correctness.

Typed ordered actions and scheduled single-step timers now have a separate
[29-obligation contract](lean-scheduled-microsteps.md). Complete case actions
compile and nine frozen native/reference transitions match compiled Lean. This
unit does not by itself certify batched scheduling or universal rule preservation
before runtime invariant filtering; those have separate timed proof obligations.

An all-rule timer-free integer EFSM contract now feeds the complete ten-stage
flow through explicit task-v6. It checks preservation before runtime filtering,
disjointness, total state/event coverage, initial validity and admitted literal
witnesses. This is a larger proof boundary than the earlier selected action block;
it still excludes timers/bytes/native arithmetic and interpreter/compiler proofs.
See [Lean EFSM flow](lean-efsm-flow.md). The typed v7 and reviewed timed v8
contracts extend this boundary with separately stated scopes.

The Python package installs without solver dependencies. An integer, timer-free action-block
unit now checks ordered set/emit and final-invariant rollback. See the
[supported fragments](lean-first.md). The old solver backend is retired from
the maintained package; historical receipts require their original revision.
Neither milestone replaces whole-EFSM checking or proves C statements.

Extend the typed pure expression fragment to statements and its evaluation contract.
Establish a checked connection to a C subset or per-output translation validation,
starting with byte access/slices and conditional evaluation. Then cover ordered
updates, failures/rollback and expression factoring. Keep all protocol decisions
in the single authoritative IR; derived proof views are not another protocol spec.

## Next: broader, independently scored benchmark

Add several small protocols beyond the byte unit and mailbox. Freeze source
interpretations, supported domains, normal-run witnesses and adversarial cases.
Score modeling, implementation generation, proof obligations and fault detection
separately. Reachability, nonvacuity, invariant preservation and delivery are
separate claims. Specification amendments require a reviewed new approval epoch.

## Next: persistent provider-neutral agent controller

Build an obligation/dependency queue over the deterministic interfaces. Give
workers isolated candidate state and explicit allowed edits; use bounded tool
feedback and a single integrator. Cache completed obligations by complete input,
semantics and checker identity. Expose the same workflow to CLI, MCP, Skills or
other agent harnesses. Failed/uncertain provider calls remain terminal rather
than being silently paid for again. The checker, not an agent, owns completion.

## Typed batch scheduler checkpoint

The actual selector/action/timer semantics now support a kernel-checked total
batch scheduler with whole-batch rollback and no fuel cutoff. A checked replay
bridge decomposes it into real selector/step equations. Compiled Lean matches
22 frozen operations. Its 57-obligation literal certificate now checks using
exact next-step equations and stronger byte-content lemmas; the original resource
UNKNOWN attempts remain independent history. Extend universal typed-rule
preservation/coverage before whole-case/full-flow migration; do not
cover full protocol or compiler correctness. See [batch scheduling](lean-batch-scheduling.md).

## Universal typed EFSM checkpoint

The timer-free atomic fragment now has raw before-filter preservation, initial
validity, guard disjointness and declared-state/event coverage for all five value
kinds. Typed Cell's 14 obligations and fresh kernel recheck pass; eight new tests
also reject wrong-byte execution, incomplete witnesses/oracles and certificate
mutations. The independent base installation checks this without importing Z3.
Explicit task-v7 now runs the full typed flow and bounded native text input.
Timed Cell's universal timed flow (`examples/lean-timed-efsm/flow.json`) runs
all ten `spec-flow-task-v8` stages, and the pinned TCP/IP endpoint proof is
checked on Lean 4.35.0; native/compiler refinement and complete TCP/IP protocol
reachability remain separate obligations.
The 64-message-per-literal, 128-case/128-step and 512-total-step limits are
explicit witness-generation resource limits; they do not restrict the universal
store/field quantifiers in preservation or coverage.

## Timed contracts checkpoint

Generic raw firing and actual fire/external/timer preservation bridges are now
kernel-checked. Timed Cell has independent ten-operation reference/native checks,
a finite `checked_timed_replay` certificate, and the complete ten-stage
`spec-flow-task-v8` universal flow (`examples/lean-timed-efsm/flow.json`) with
checked initial admission, raw rule preservation, guard disjointness and timer
coverage. Unknown timer fields are explicitly rejected by typed machine admission.
The microstep approval epoch changes only its adapter pin, not its propositions.
