# Typed scheduled microstep benchmark

Protocol IR is `model.json`; its interpretation is fixed in `spec.md`. Independent
literal outcomes in `cases.json` cover seven initial contexts and18 operations:
ordered writes, all five value types, source-state emissions, two tied timers,
rearm/cancel, positive-delay enforcement, final-invariant rollback, conflicts,
uncovered events, timer injection, backward time and4096 exact bytes/Unicode/NUL.
The timer declaration order is deliberately the reverse of lexical order.

`task.json` pins those inputs and29 kernel obligations; `proofs.json` contains only
restricted proof data. Full C99 execution and Python reference checks are separate
from actual Lean checking and compiled Lean reference execution. This is an
explicit microstep contract, not automatic batch dispatch or all-rule safety.

`tcpip-cases.json` is an exact nine-transition projection from the unchanged
pre-optimization TCPIP native/reference fixture. `tcpip-provenance.json` binds
its original Git source and hashes. Expected outputs are never regenerated by
running a changed implementation. See [scope and commands](../../docs/lean-scheduled-microsteps.md).
